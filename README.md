# 박준하 | Joooooonha

주변에서 생기는 문제를 관찰하고, 직접 만들어 검증할 때 가장 몰입합니다.

가장 깊게 파는 분야는 백엔드입니다. 안정적으로 **제가 없어도 돌아가는 것**을 만드는 데 성취감을 느낍니다. 문제에 필요한 기술이 낯설다면 분야를 제한하기보다 먼저 사용해 보고, 실패와 예외를 기록하며 배웁니다.

## How I Work

- **관찰하고 질문합니다.** 떠오른 기능이 아니라 누가 어느 순간에 막히는지부터 확인합니다.
- **작동하는 형태로 끝냅니다.** 백엔드뿐 아니라 iOS, 프론트엔드, 비전 기술까지 필요한 범위를 배워 연결합니다.
- **실패를 근거로 남깁니다.** 성공한 화면만 보여주기보다 적용 범위, 예외와 다음 판단을 문서화합니다.
- **함께 성장합니다.** 아는 것은 나누고, 낯선 분야는 말랑말랑하게 흡수하려고 합니다.
